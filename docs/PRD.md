# 견적서 웹뷰어 MVP PRD

## 🎯 핵심 정보

**목적**: 노션(Notion)에 입력한 견적서 데이터를 클라이언트가 별도 로그인 없이 웹에서 확인하고 다운로드할 수 있게 한다
**사용자**: 견적서를 발행하는 프리랜서/소규모 대행사(발행자)와 그 견적서를 받는 클라이언트(열람자)

## 🚶 사용자 여정

```
[발행자 플로우]
1. 로그인 페이지
   ↓ 로그인 성공

2. 대시보드 페이지
   ↓ 노션 연동 안 되어 있음 → 노션 연동 설정 페이지 → 연동 완료 → 대시보드 페이지로 복귀
   ↓ 동기화 버튼 클릭

3. 대시보드 페이지 (견적서 목록 갱신)
   ↓ 특정 견적서의 "공유 링크 생성" 클릭

4. 공유 링크 복사 완료 → 클라이언트에게 링크 전달(메신저/이메일 등 외부 채널)

[열람자(클라이언트) 플로우]
1. 견적서 공유 페이지 (공유 링크로 진입, 로그인 불필요)
   ↓ 견적 내용 확인

2. 다운로드 버튼 클릭
   ↓

3. 파일 다운로드 완료
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 견적서 동기화 | 노션 데이터베이스에 입력된 견적서 데이터를 불러와 웹 서비스에 반영 | 노션 입력만으로 웹 게시가 가능해야 핵심 가치가 성립함 | 대시보드 페이지 |
| **F002** | 견적서 상세 열람 | 클라이언트가 공유 링크로 접속해 품목/단가/수량/합계 등 견적 내용을 확인 | 클라이언트가 웹에서 견적을 확인하는 것이 서비스의 핵심 목적 | 견적서 공유 페이지 |
| **F003** | 견적서 다운로드 | 클라이언트가 웹에서 확인한 견적서를 파일로 다운로드 | "웹으로 다운받을 수 있는" 요구사항의 핵심 기능 | 견적서 공유 페이지 |
| **F004** | 공유 링크 생성 | 발행자가 특정 견적서에 대한 고유 공유 링크를 생성하고 복사 | 클라이언트에게 견적서를 전달할 유일한 통로 | 대시보드 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F010** | 기본 인증 | 발행자 회원가입/로그인/로그아웃 | 발행자별 견적서를 구분해 관리하기 위한 최소 인증 | 로그인 페이지, 회원가입 페이지 |
| **F011** | 노션 연동 설정 | 발행자가 자신의 노션 데이터베이스와 연동하기 위한 정보를 등록 | F001(견적서 동기화)이 동작하기 위한 선행 설정 | 노션 연동 설정 페이지 |

### 3. MVP 이후 기능 (제외)

- 견적서 열람 여부/조회 이력 확인
- 견적서에 대한 클라이언트 코멘트/승인 기능
- 다중 팀원 계정 및 권한 분리
- 커스텀 도메인 지원
- 견적서 템플릿 디자인 커스터마이징
- 공유 링크 비밀번호/만료 기한 설정

## 📄 페이지별 상세 기능

### 로그인 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 시 노출

| 항목 | 내용 |
|------|------|
| **역할** | 발행자 인증 전용 페이지 |
| **진입 경로** | 비로그인 상태에서 서비스 접속 시 자동 이동, 또는 회원가입 페이지에서 이동 |
| **사용자 행동** | 이메일/비밀번호 입력 후 로그인 |
| **주요 기능** | • 이메일/비밀번호 입력 폼<br>• 로그인 유효성 검사(형식/필수값)<br>• 회원가입 페이지로 이동 링크<br>• **로그인** 버튼 |
| **다음 이동** | 성공 → 대시보드 페이지, 실패 → 에러 메시지 표시 |

---

### 회원가입 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 시 노출

| 항목 | 내용 |
|------|------|
| **역할** | 발행자 계정 생성 전용 페이지 |
| **진입 경로** | 로그인 페이지에서 이동 |
| **사용자 행동** | 이메일/비밀번호/이름 입력 후 계정 생성 |
| **주요 기능** | • 회원가입 입력 폼(이메일, 비밀번호, 이름)<br>• 입력값 유효성 검사(Zod 스키마 기반)<br>• 로그인 페이지로 이동 링크<br>• **가입하기** 버튼 |
| **다음 이동** | 성공 → 로그인 페이지(또는 대시보드 페이지로 자동 로그인), 실패 → 에러 메시지 표시 |

### 대시보드 페이지

> **구현 기능:** `F001`, `F004` | **인증:** 로그인 필요

| 항목 | 내용 |
|------|------|
| **역할** | 발행자가 견적서 목록을 확인하고 공유를 준비하는 메인 작업 공간 |
| **진입 경로** | 로그인 성공 시 자동 이동, 헤더 메뉴 "대시보드" 클릭 |
| **사용자 행동** | 동기화 버튼으로 노션 데이터를 불러오고, 견적서별로 공유 링크를 생성/복사 |
| **주요 기능** | • 견적서 목록 표시(견적명, 클라이언트명, 합계 금액)<br>• 노션 데이터 **동기화** 버튼<br>• 노션 미연동 시 연동 설정 페이지로 안내<br>• 견적서별 **공유 링크 생성/복사** 버튼 |
| **다음 이동** | 노션 미연동 → 노션 연동 설정 페이지, 공유 링크 생성 완료 → 대시보드 페이지 내 링크 복사 완료 표시 |

---

### 노션 연동 설정 페이지

> **구현 기능:** `F011` | **인증:** 로그인 필요

| 항목 | 내용 |
|------|------|
| **역할** | 발행자의 노션 데이터베이스와 서비스를 연결하는 설정 전용 페이지 |
| **진입 경로** | 대시보드 페이지에서 "노션 연동 설정" 메뉴 클릭, 또는 미연동 상태에서 대시보드 진입 시 자동 안내 |
| **사용자 행동** | 노션 연동 정보(연동 키, 데이터베이스 ID)를 입력해 연결 |
| **주요 기능** | • 노션 연동 정보 입력 폼<br>• 연동 정보 유효성 검사<br>• 연동 상태 표시(연동됨/미연동)<br>• **연동 저장** 버튼 |
| **다음 이동** | 성공 → 대시보드 페이지, 실패 → 에러 메시지 표시 |

### 견적서 공유 페이지

> **구현 기능:** `F002`, `F003` | **인증:** 불필요(공유 링크 소지자 누구나 접근)

| 항목 | 내용 |
|------|------|
| **역할** | 클라이언트가 견적 내용을 확인하고 다운로드하는 열람 전용 페이지 |
| **진입 경로** | 발행자로부터 전달받은 공유 링크로 직접 접속 |
| **사용자 행동** | 견적서 내용을 확인하고 파일을 다운로드 |
| **주요 기능** | • 견적서 기본 정보 표시(견적명, 발행자, 클라이언트명, 발행일)<br>• 품목/단가/수량/소계/합계 테이블 표시<br>• **다운로드** 버튼<br>• 유효하지 않은 링크 접근 시 안내 메시지 |
| **다음 이동** | 다운로드 완료 → 동일 페이지 유지, 링크 무효 → 에러 안내 화면 |

## ✅ 정합성 검증 결과

- **기능 명세 → 페이지 연결**: F001~F004, F010, F011 모두 페이지별 상세 기능에 해당 페이지로 존재함
- **메뉴 구조 → 페이지 연결**: 메뉴의 로그인/회원가입/대시보드/노션 연동 설정 항목 모두 페이지별 상세 기능에 존재함
- **페이지별 상세 기능 → 역참조**: 각 페이지의 구현 기능 ID(F001~F004, F010, F011)가 모두 기능 명세에 정의되어 있음
- **누락/고아 항목**: 기능 명세에만 있고 페이지가 없는 기능 없음, 페이지에만 있고 기능 명세에 없는 기능 없음, 메뉴에만 있고 페이지가 없는 항목 없음
